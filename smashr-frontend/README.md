# React + Vite Project

A fast, modern React application bootstrapped with [Vite](https://vitejs.dev/), offering lightning-fast builds and hot module replacement.

## 🚀 Getting Started

Follow the steps below to run this project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v14.18+, 16+ recommended)

### 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   cd your-repo-name
   ```

2. Install dependencies

    ```
    npm install
    ```

### 🏃‍♂️ Running the Dev Server

Start the development server:

    ```
    npm run dev
    ```

The app will be available at http://localhost:5173 by default.

### ⚙️ Available Scripts
npm run dev – Start the development server

npm run build – Build the app for production

npm run preview – Preview the production build locally

npm run lint – Run linter (if configured)
