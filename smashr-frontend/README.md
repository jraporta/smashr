# React + Vite Project

A fast, modern React application bootstrapped with [Vite](https://vitejs.dev/), offering lightning-fast builds and hot module replacement.

## 🚀 Getting Started

Follow the steps below to run this project locally.

### Prerequisites

- [Node.js](https://nodejs.org/) (v14.18+, 16+ recommended)

### 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/jraporta/smashr.git
   cd smashr/smashr-frontend
   ```

2. Install dependencies

    ```
    npm install
    ```

### 🏃‍♂️ Running the Dev Server

1. Start the development server:

    ```
    npm run dev
    ```

The app will be available at http://localhost:5173 by default.

### ⚙️ Available Scripts
- `npm run dev` — Starts the development server
- `npm run build` — Builds the app for production
- `npm run preview` — Previews the production build locally

## 🧰 Tech Stack

**Frontend:**

- [React 19](https://reactjs.org/)
- [React Router DOM 7](https://reactrouter.com/)
- [Vite](https://vitejs.dev/) — fast dev server & build tool
- [Tailwind CSS 4](https://tailwindcss.com/) — utility-first styling
- [Lucide React](https://lucide.dev/) — icon library
- [Axios](https://axios-http.com/) — HTTP client
- [Date-fns](https://date-fns.org/) — date utilities
- [Slugify](https://www.npmjs.com/package/slugify) — string slugging
- [iso8601-duration](https://www.npmjs.com/package/iso8601-duration) — parse ISO 8601 durations

**Testing:**

- [Vitest](https://vitest.dev/) — unit testing
- [Testing Library (React, DOM, User Event)](https://testing-library.com/)
- [JSDOM](https://github.com/jsdom/jsdom)

**Linting & Dev Tools:**

- [ESLint](https://eslint.org/) with React & Hooks plugins
- [@vitejs/plugin-react](https://www.npmjs.com/package/@vitejs/plugin-react)
